# Personal portfolio

Dark personal index in one 720px reading column. Compact name and color portrait, 16px body text, restrained headings, and a horizontal section navigation. Existing Inter font, neutral #111315 canvas, #e9ecea text, #abb0ad secondary text, and #303438 separators.

Each section has its own URL and shows only its own content. No slogans, emojis, oversized hero, decorative colors, or animations. Mobile uses a 24px name and 64 by 80px portrait. Links have visible keyboard focus and hover underlines. Original CV facts and publication statuses remain authoritative.
